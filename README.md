# 🚀 Руководство по установке и запуску проекта PIDIS_Lakin

Данный документ описывает минимальные требования и пошаговый процесс развёртывания проекта **PIDIS_Lakin** на локальной машине или сервере.

---

## 📋 Что нужно, чтобы сайт заработал

Для функционирования проекта необходимы следующие компоненты:

- **Веб-сервер** с поддержкой PHP (Apache, Nginx или встроенный сервер PHP).
- **PHP** версии 7.4 или выше (рекомендуется PHP 8.0+).
- **MySQL** или **MariaDB** (для хранения данных).
- **Composer** (опционально, если в проекте появятся зависимости; на текущий момент `composer.json` отсутствует).

---

## 📦 Зависимости

### Системные пакеты
- `php` (с расширениями `pdo`, `pdo_mysql`, `mbstring`, `json`).
- `mysql-server` или `mariadb-server`.
- `apache2` или `nginx` (или используйте встроенный сервер PHP).

### Расширения PHP
Убедитесь, что включены следующие расширения:
- `pdo_mysql` — для подключения к базе данных.
- `mbstring` — для работы с многобайтовыми строками.
- `json` — для обработки JSON (используется в API).

### Внешние библиотеки
Проект не содержит `composer.json` или `requirements.txt`, поэтому дополнительные PHP-пакеты через Composer не требуются. Все зависимости — стандартные расширения PHP.

## 🛠️ Как запустить сайт (последовательность действий)

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/VizeRsir/PIDIS_Lakin.git
cd PIDIS_Lakin
```

### Шаг 2. Создание базы данных
1. Войдите в MySQL/MariaDB:
   ```bash
   mysql -u root -p
   ```
2. Создайте базу данных (имя можно изменить, но тогда потребуется правка конфигурации):
   ```sql
   CREATE DATABASE project_Lakin CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
3. Выйдите из консоли MySQL.

### Шаг 3. Импорт структуры БД
В проекте есть файл `project_V1z/notes_api/install.sql`. Выполните его для создания необходимых таблиц:
```bash
mysql -u root -p project_Lakin < project_V1z/notes_api/install.sql
```
> **Примечание:** Если файл `install.sql` отсутствует в вашей копии, создайте таблицы `notes` и `users` вручную, руководствуясь кодом из `debug.php` и `notes.php`.

### Шаг 4. Настройка подключения к БД
Откройте файл `project_V1z/notes_api/config/db.php` и укажите ваши локальные параметры подключения:
```php
<?php
return [
    'host'    => '127.0.0.1',
    'port'    => 3306,
    'db'      => 'project_Lakin',
    'user'    => 'ваш_пользователь',
    'pass'    => 'ваш_пароль',
    'charset' => 'utf8mb4',
];
```
> **Важно:** В оригинальном файле указаны удалённые учётные данные. Для локального запуска обязательно замените их на свои.

### Шаг 5. Запуск веб-сервера
Выберите один из способов:

#### Вариант А. Встроенный сервер PHP (быстрый старт)
Перейдите в корневую папку проекта и выполните:
```bash
php -S localhost:8000
```
После этого сайт будет доступен по адресу `http://localhost:8000`.  
> **Обратите внимание:** Встроенный сервер не обрабатывает `.htaccess`, поэтому убедитесь, что все ссылки ведут на конкретные `.php`-файлы (например, `http://localhost:8000/project_V1z/zhkh_docs/admin/dashboard.php`).

#### Вариант Б. Apache / Nginx (рекомендуется для production)
1. Настройте виртуальный хост, указав корневую директорию на папку `project_V1z/zhkh_docs` (или на корень проекта, если требуется доступ к API).
2. Убедитесь, что модуль `mod_rewrite` включён (если планируется использовать ЧПУ).
3. Перезапустите веб-сервер.

### Шаг 6. Проверка работоспособности
- Откройте в браузере `http://localhost:8000/project_V1z/zhkh_docs/` (или адрес вашего виртуального хоста).
- Для проверки API перейдите по адресу `http://localhost:8000/project_V1z/notes_api/api/notes.php` — должен вернуться JSON-ответ.
- Запустите `debug.php` (например, `http://localhost:8000/project_V1z/notes_api/debug.php`), чтобы убедиться в успешном подключении к БД и наличии таблиц.

## ⚠️ Важные замечания

- **Безопасность:** Никогда не используйте удалённые учётные данные из `db.php` в production. Всегда создавайте отдельного пользователя БД с ограниченными правами.
- **Права доступа:** Убедитесь, что веб-сервер имеет права на чтение файлов проекта.
- **Конфигурация PHP:** Если используете Apache, проверьте, что директива `AllowOverride` разрешает `.htaccess` (при необходимости).
- **Тестирование:** Файл `tests.http` содержит примеры запросов к API — используйте его для проверки эндпоинтов.
