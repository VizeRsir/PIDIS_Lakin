# 🚀 Руководство по установке и запуску проекта PIDIS_Lakin

Данный документ описывает минимальные требования и пошаговый процесс развёртывания проекта **PIDIS_Lakin** на локальной машине или сервере.

---

## 📋 Что нужно, чтобы сайт заработал

Для функционирования проекта необходимы следующие компоненты:

- **Веб-сервер** с поддержкой PHP (Apache, Nginx или встроенный сервер PHP).
- **PHP** версии 7.4 или выше (рекомендуется PHP 8.0+).
- **MySQL** или **MariaDB** (для хранения данных).
- **Composer** (опционально, если в проекте появятся зависимости; на текущий момент `composer.json` отсутствует).

---

## 📦 Зависимости

### Системные пакеты
- `php` (с расширениями `pdo`, `pdo_mysql`, `mbstring`, `json`).
- `mysql-server` или `mariadb-server`.
- `apache2` или `nginx` (или используйте встроенный сервер PHP).

### Расширения PHP
Убедитесь, что включены следующие расширения:
- `pdo_mysql` — для подключения к базе данных.
- `mbstring` — для работы с многобайтовыми строками.
- `json` — для обработки JSON (используется в API).

### Внешние библиотеки
Проект не содержит `composer.json` или `requirements.txt`, поэтому дополнительные PHP-пакеты через Composer не требуются. Все зависимости — стандартные расширения PHP.
